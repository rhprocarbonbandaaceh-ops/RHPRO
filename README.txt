RH PRO RACING TIMER - GitHub Actions helper

1. Create a GitHub repository.
2. Upload the original file RH_PRO_RACING_TIMER_v2_icon_speedometer.zip to the repository root.
3. In GitHub, choose Add file > Create new file.
4. For the filename, enter exactly: .github/workflows/build-apk.yml
5. Open the downloaded build-apk.yml file, copy all its contents into the GitHub editor, and Commit changes.
6. Open the repository's Actions tab. Open "Build RH PRO RACING TIMER APK". If needed, choose Run workflow.
7. When the run completes successfully, open the run and download the artifact named RH-PRO-RACING-TIMER-APK.

Important: This workflow builds the project ZIP as uploaded. It may fail if the source project needs corrections. This is a debug APK, not a signed release APK.
